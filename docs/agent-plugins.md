# 自定义 Agent 与插件

## 导入 Agent

1. 在 **设置 → Agent → 自定义 Agent 类型 → 导入 Agent** 选择一个 `.json` 配置或 `.cjs` / `.mjs` / `.js` 自描述脚本。
2. 确认或修改名称，点 **保存 Agent 类型**。不需要填写命令、选择程序或启用扩展。
3. 新建会话选择该类型。有原生历史能力时，在对话历史页点 **读取对话**；支持刷新、选择文件和关联原生 ID。

启动命令和能力都由文件提供。软件复制脚本及清单资源到自身管理目录，移动或删除下载目录不会影响使用；Node 脚本使用软件自带运行时。旧版多文件 `agentberth-plugin.json` 和独立可执行适配器仍可导入。脚本会在本机执行，请导入可信来源的文件。实际 Agent CLI 仍使用本机安装和登录状态。

**热更新（后台 API 15）**：在类型旁点“更新插件”，选择更新后的配置或脚本。校验成功后直接替换，无需再次填写名称、停止终端或重启工作台。名称、类型 ID、默认设置和历史关联保留，之后的发现、读取和恢复使用新版；失败继续使用旧版。运行中也可以重新导入相同 ID 的文件并保存。更新前已发出的旧版请求不会覆盖新版结果，也不会用旧恢复命令启动终端。已有会话保存自己的启动命令，新命令用于以后新建的会话。可用“检查插件”查看能力是否正常。

## 多会话历史与关联

在“对话历史”中，“已保存的会话”展示同项目、同 Agent 类型已导入/关联的所有 ID，支持标题/ID 搜索、每页 5/10/20 条和上一页/下一页。重复导入相同 ID 更新该条，不会覆盖其他 ID；已有 0.8 历史会自动迁移。

点选条目先预览，点击“关联”才将它设为当前目标；也可手动填写 ID。每个工作台会话保留一个当前关联，项目目录下可保留多条候选历史。已保存目录在同项目、同类型的工作台会话间共享，关联状态互不影响。

**终端运行中可以关联、切换和解除关联。** 这些操作只更新工作台历史和下次恢复目标，当前 CLI、PTY、命令及 PID 都保持不变。解除关联不会删除目录中的历史或 Agent 原生文件。停止后从侧栏选择“恢复原生会话”，才会用新 ID 启动。

插件声明可选 list 能力后会出现“发现会话”，分页列出尚未导入的原生会话。预览和刷新支持按 ID 读取；旧插件不提供 list 时，可继续导入多个文件或手动关联 ID。内置 Codex/Claude/OpenCode 当前列出已导入或手动关联的记录，不扫描 CLI 的私有数据库目录。

历史文件路径和读取器/插件的提示集中在对话上方的“读取详情”中，默认收起；重复提示合并并标注次数。多条会话或内容不完整会在摘要中提示，读取失败仍单独报错。扫描跳过无效或其他项目的候选文件不等于当前对话损坏。已知英文提示提供中文说明，原文可通过悬停查看；未知插件提示原样保留。

## 让编程 Agent 开发插件

在 **设置 → Agent** 点击 **导出开发套件**，选择保存位置。软件生成新目录，包含完整开发指南、清单、可运行模板和独立检查工具 check-plugin.cjs，并自动复制开发指令。把指令粘贴给编程 Agent，告诉它你要适配的 CLI 和历史/恢复需求即可。开发 Agent 可直接检查协议、多会话分页和按 ID 读取，检查失败时得到具体原因；你仍只需导入它交付的文件。

也可以直接点击 **复制 Agent 开发指令**，无需先导出；指令包含完整指南。仓库中的 [AGENT_PLUGIN_DEVELOPMENT.md](AGENT_PLUGIN_DEVELOPMENT.md) 可直接交给 Agent 阅读，模板位于 [examples/plugin-template](../examples/plugin-template)。软件包 resources/docs 和 resources/examples 同样包含这些文件。

完成后只需导入 Agent 交付的文件。仅启动用 agent.json；带能力的单脚本直接选 plugin.cjs，有额外资源才选清单。模板读取标准 JSON `agent-session.json` 以及 `agent-sessions/*.json`，演示分页 list 与按 ID history，并非现成的 Aider/Gemini 等真实 CLI 适配器；开发 Agent 应根据实际 CLI 文档和原生记录实现并测试。

## 日常配置

项目、会话的所有管理入口统一在左侧条目的右键或 ⋯ 菜单：新建、重命名、编辑、复制、删除、启动／停止和原生恢复。右键未选中的条目不会切走当前会话，删除与停止都有明确目标。也可聚焦条目后按 Shift+F10，方向键选择、Enter 执行、Esc 关闭。右侧只展示内容和状态。终端缩放按输出顺序同步前后台字符网格；拖动侧栏或调整窗口后，会话仍保持原 PID。

不用历史/恢复扩展时，导入仅包含 schemaVersion、id、name 和 command 的 JSON 配置即可（示例见开发指南）。名称随时可改；命令和能力通过“更新插件”或重新导入更新。旧版手动保存的配置继续可用。

项目和会话名称可留空，自动按目录或 Agent 生成；会话终端默认跟随设置，只有需要覆盖时才展开调整。单个项目可有多个独立会话，设置中的默认 Agent 用于之后新建的会话。

## 记录策略

**只有普通 Shell 会话保存运行输出和运行记录。** Codex、Claude Code、OpenCode、旧版自定义命令及保存的自定义 Agent 类型均不录制 TUI 屏幕，不显示运行记录或结束后的“查看本次输出”。它们保留当前运行状态和已有原生对话历史，实时画面仍支持隐藏窗口后接回。

默认终端指“普通终端”会话，并不限制为某个 Shell 程序：PowerShell、CMD、Bash 或自定义 Shell 都可用。Agent 自身的原生对话记录由内置读取器或插件管理，与终端输出分开。
