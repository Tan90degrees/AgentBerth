# 项目文件与预览

在工作台顶部点击“文件”，展开当前项目的目录树和预览面板。它与终端并排显示；关闭面板会归还空间，终端始终继续运行。拖动面板左边缘调整宽度，双击恢复默认；聚焦分隔线后也可用左右方向键调整。

## 目录树

- 点击目录展开或收起，点击文件预览。上下方向键移动，左右方向键展开、收起或返回父目录，Home / End 跳到首尾。
- 只读取展开的目录。单页 200 项，可点击“加载更多”；一个目录最多扫描 10,000 项，并明确提示截断。
- Git 忽略的条目显示为灰色，也可点击“隐藏忽略项”。由 `git check-ignore` 判断，保留嵌套 `.gitignore`、否定规则、`.git/info/exclude`、`core.excludesFile` 和已跟踪文件语义。
- 普通目录也能浏览；不是 Git 仓库或 Git 暂不可用时，文件列表继续工作。后者会提示忽略状态不可用。
- 点击刷新按钮会重新读取展开的目录和当前文件；切回工作台窗口也会刷新。文件被终端或 Agent 修改后无需停止会话。

## 预览

- 文本支持 UTF-8，以及带 BOM 的 UTF-16 LE / BE。源码带行号，代码高亮在独立 Worker 中执行；未知语言保留纯文本。
- 支持常见 JS / TS、Python、C / C++、Java、JSON、YAML、Shell、PowerShell 等语言。复制按钮复制当前预览的内容，刷新按钮重新读取当前文件。
- Markdown 默认渲染，也可切换为源码；记住所选模式。支持表格、任务列表、代码块、本地图片及项目内文档链接。网页链接通过默认浏览器打开；外部图片显示为可打开的链接。
- 可预览 PNG、JPEG、GIF、WebP、BMP、ICO 和 AVIF。SVG 作为 XML 源码查看。
- 文本最多读取 256 KiB / 10,000 行；超出会明确提示只预览开头部分。图片最大 4 MiB。二进制、不可访问文件和空文件有独立状态。

只读取当前项目内的文件；指向项目外的符号链接不能展开或预览。Markdown 不执行嵌入的 HTML 或脚本，也不直接加载远端图片。文件浏览是只读功能，不修改项目文件。

## 开发验证

`npm run test:files` 构建并验证真实 Electron 文件面板。Linux 需要显示服务，例如 `xvfb-run -a npm run test:files`。完整桌面和打包回归自动包含这组测试，覆盖忽略灰显、分页、Markdown 源码 / 渲染、代码高亮、本地图片、刷新、项目切换隔离和终端 PID 保持。
