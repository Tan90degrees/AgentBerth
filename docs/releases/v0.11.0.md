# StackIsle · 栈屿 v0.11.0

AgentBerth 更名为 **StackIsle（栈屿）**：按项目组织的本地开发工作台，汇集持续运行的终端、Agent、文件和历史。新图标使用深海军蓝底、象牙白与薄荷绿的叠层岛屿。

- 左侧在“会话 / 文件”之间切换，主区在“终端 / 历史 / 预览”之间切换；预览占用完整内容区，没有会话也能浏览文件。
- 切换预览或历史保留终端实例、选区与滚动状态；不重新连接、不停止终端。
- Ctrl（macOS ⌘）点击终端中的文件路径，唯一匹配直接预览，多个匹配弹出候选列表；目录定位到左侧树。支持绝对路径、相对路径、模糊缩写和 `:行:列`；换行的终端路径也可识别。
- 文件侧栏提供“查找文件或目录”，支持方向键与回车；Ctrl+Shift+E 切换侧栏视图。
- 文件预览工具栏合并为一行，保留语法高亮、Markdown 源码/渲染、图片预览与复制。

升级继续使用原有应用标识与数据目录，保留项目、会话、插件、设置和运行记录；安装器识别旧版 AgentBerth.exe 并阻止覆盖正在运行的旧进程。安装包和可执行文件改名为 StackIsle。GitHub 仓库地址与插件协议标识保持兼容。

Windows 下载：`StackIsle-0.11.0-windows-x64-setup.exe`（安装器）或 `StackIsle-0.11.0-windows-x64.zip`（解压运行 StackIsle.exe）。
