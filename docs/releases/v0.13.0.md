# AgentBerth · 泊栈 v0.13.0

预览外观统一管理，Git 操作集中到左侧源代码管理视图。

- **设置 → 文件预览**统一调整字体、字号，沿用已有选择，对所有项目的源码、Markdown 和 Git 差异生效。
- 左侧 **会话 / 文件 / Git** 切换；顶部的分支入口和项目右键也会转到 Git 侧栏。Ctrl+Shift+G 快速打开。
- 更改与已暂存内容分组，支持逐文件与多选暂存、取消暂存、文件筛选和分页显示。
- 填写提交信息后提交已暂存内容，Ctrl+Enter 可快捷提交；草稿按项目保留，工作目录中的后续修改保留。
- 点击更改文件在主区预览未暂存/已暂存差异，显示增删行、双行号与上下文，支持新建、删除、重命名及二进制状态。
- 分支和远端同步位于侧栏的折叠区域；进入设置、切换视图与执行 Git 操作继续保留终端实例。

Windows 下载：`AgentBerth-0.13.0-windows-x64-setup.exe` 或 `AgentBerth-0.13.0-windows-x64.zip`。
