# AgentBerth v0.19.0

- 新增服务终端：普通终端可指定启动命令，以只读日志显示输出，支持启动、停止、重启和进程树清理，沿用退出恢复。
- 新增 DeepSeek Harness 原生 Web 插件，直接启动官方服务并在隔离浏览器视图中显示原生界面；支持启停、刷新、日志和启动配置，ACP 由用户在通用入口接入。
- 工作台顶部合并为单行，移除顶部折叠开关；项目和项目内会话支持拖动及 Alt＋↑/↓ 排序，顺序自动保存，不切换或重启活动终端。
- 会话树支持全部展开和全部折叠；扩展应用集中到可搜索列表，标签、标题和工具栏压缩留白。
- ACP 默认启动等待调整为 180 秒，可配置 5–600 秒，支持取消连接并显示启动错误日志；按实际能力支持原生会话恢复与关闭。
- 关机回归单独限制响应和关闭握手时间，避免 Windows 冷启动耗时占用协议验证预算。

后台 API 51 / schema 8。schema 6/7 数据自动添加服务字段，普通会话默认关闭服务模式；无需清除现有数据。更新后台后使用新增能力。未捆绑 Agent，也不修改 DeepSeek Harness 的模型、账号或沙箱权限。
