# AgentBerth v0.8.0 · 泊栈首个公开版本

面向 Windows 的项目与 Agent 终端工作台。按项目组织会话，关闭主窗口后继续运行，从托盘退出时停止全部终端及后台。

## 功能

- 可调整宽度的项目／会话树；左侧右键或 ⋯ 菜单统一新建、重命名、编辑、复制、删除、启动和停止。
- Codex、Claude Code、OpenCode、普通终端，以及可新增保存的多种自定义 Agent 类型。
- 默认终端、默认 Agent、默认命令和字号；自动发现 PowerShell 7，可覆盖程序路径或使用 CMD、Bash、自定义 Shell。
- 原生对话关联、刷新和恢复；自定义 Agent 插件清单导入、自带 Node 运行时、自检、开发套件及完整 Agent 开发指南。
- 窗口／侧栏缩放与输出按顺序同步，连续拖动合并请求；中文、emoji、查找、复制、括号粘贴、链接和独立滚动条空间。
- 仅普通 Shell 保留运行输出；Agent TUI 不录屏，不把屏幕重绘当成对话。
- 统一应用、安装程序、任务栏、托盘图标；设置提供版本、诊断信息复制和数据目录入口。

## 安装和开始使用

1. 下载 `AgentBerth-0.8.0-windows-x64-setup.exe` 安装，或将 `AgentBerth-0.8.0-windows-x64.zip` 完整解压后运行 `AgentBerth.exe`。
2. 在设置中选择默认终端和 Agent，添加项目目录。
3. 右键项目新建会话，选择 Agent 后创建并启动。关闭窗口继续工作；需要完全退出时使用托盘的“退出 AgentBerth（停止全部终端）”。

软件自带 Electron、Node 和 PTY，无需为应用安装开发工具。实际 Agent CLI 需自行安装并登录，插件模板需要按目标 CLI 适配后使用。

## 从开发版本升级

先停止全部终端并从托盘退出旧应用，再安装新版。项目、会话和设置保留；若提示旧后台仍在运行，在“设置 → 更新后台”完成切换。数据库为本机持久化数据，重要数据可在退出后备份数据目录。

## 范围和限制

- 提供 Windows x64 安装包与 ZIP，主要面向 Windows 10 1809+／Windows 11；CI 在 Windows 和 Linux 验证。暂不提供 macOS、Linux 安装包、WSL 或远程后台。
- 安装包尚无代码签名，Windows 可能提示未知发布者。可用 `SHA256SUMS.txt` 校验下载文件；`build-info.json` 记录提交与打包测试结果。
- 原生历史展示文本消息，暂不支持完整工具调用、多模态内容、压缩历史和自动扫描。
- ConPTY 对满行显式换行与软换行的区分仍有歧义；CI 使用真实 PTY 和 TUI 替身验证，不访问 Agent 账号。
- 最多同时运行 16 个终端。普通终端日志和重连快照有容量上限；主动停止会终止进程树。
