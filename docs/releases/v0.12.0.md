# AgentBerth · 泊栈 v0.12.0

项目名称恢复为 **AgentBerth · 泊栈**，保留新的目录导航布局和图标。

- 终端文件路径仅在按住 Ctrl 时显示下划线和点击手势；macOS 也支持 ⌘。未按修饰键时不会作为文件链接处理，普通点击、拖动选字与双击选词继续交给终端。
- 文件预览使用完整的 193 种内置语言语法，覆盖 JSON、YAML、TOML、常见编程语言和配置文件；工具栏可选择高亮语言，未知类型可手动选择或自动识别。
- 源码和 Markdown 代码块统一在可取消的后台 Worker 中高亮，避免主界面被高亮任务阻塞。
- 工具栏 **Aa** 可调整预览字号（10–28 px），选择常用字体或输入自定义本机字体名称。即时生效并自动保存，独立于终端字号。
- 行列跳转跟随预览字号与字体调整；源码行号避免为每一行创建额外节点。

沿用现有数据目录和应用标识，保留项目、会话、插件与设置。安装器兼容 v0.11.0 的 StackIsle.exe 升级，并识别其后台进程，避免覆盖运行中的程序。

Windows 下载：`AgentBerth-0.12.0-windows-x64-setup.exe` 或 `AgentBerth-0.12.0-windows-x64.zip`（解压运行 AgentBerth.exe）。
