# AgentBerth v0.22.0

## 新功能与修复

- ACP 与 Superagent 支持交互表单：单选、多选、多题、文本、数字与是/否，原位提交、拒绝或取消，保留原始选项值。任务内授权与表单分别处理，回答只结算原请求。
- 任务执行记录可展开查看计划、参数、结果与文件修改。轮询、切换主题及字号保留正在填写的选项，异步启动或列表刷新不会把用户拉回其他页面。
- 外观提供经典中性、蓝青、Claude 风格和液态玻璃四套配色，深色、浅色和跟随系统独立设置。界面字体支持系统、思源/Noto、衬线、等宽与自定义本机字体，自动保存并同步 HTML 插件。
- 液态玻璃使用半透明面板、柔和渐变与局部模糊，支持减少透明效果及不支持模糊时的实色回退。终端画布保持实色，同一深浅模式更换配色也会更新默认颜色查询并通知已订阅的 TUI。
- Wiki 文件和图片共用一个上传入口与「保存素材」按钮，支持纯正文、纯图片和混合资料；默认整组保存并生成一份待审阅提案，保留失败重试、原文件和未提交草稿。
- Wiki 文本、图片模型可以配置不同服务地址、鉴权与私有密钥，并分别测试连接。独立图片地址不继承文本密钥，旧的共用地址配置继续兼容。
- Wiki 可配置 LLM 调用重试次数（0–8，默认 2）与最大并发请求数（1–16，默认 2）。仅对网络、超时、限流与临时服务错误进行有界退避重试；取消会中断排队与退避，图片并行理解后按原顺序合并。插件停止的未完成编译需手动重试。

## 功能入口

- 主题与字体：左下角「设置 → 外观 → 配色主题 / 界面字体」。侧栏的外观按钮快速切换深浅模式。
- Wiki 模型：知识库「设置 → 修改模型配置」，统一配置两套服务地址、密钥、重试及并发，并分别测试连接。
- Wiki 导入：素材页「＋」，选择文件、填写可选正文后点击「保存素材」；拆分素材需要明确勾选「按文件分别导入」。

## 安装与升级

- Windows x64 安装版：`AgentBerth-0.22.0-windows-x64-setup.exe`。
- Windows x64 免安装版：`AgentBerth-0.22.0-windows-x64.zip`，完整解压后运行 `AgentBerth.exe`。
- 发布页同时提供 `SHA256SUMS.txt` 与 `build-info.json`，可核对文件、提交和 Windows 安装器/打包回归结果。
- 后台 API 64 / schema 9。从 v0.21.x 升级保留项目、会话、插件配置和 Wiki 素材，无需清空数据目录；schema 6–8 自动升级。当前架构的 API 44–63 后台仍可挂接。
- 新表单与完整终端配色协议需要更新后台。先停止活跃会话再使用后台更新入口，或从托盘完整退出旧版后重开；不重放历史输入或未完成的付费请求。

## 使用范围

- 结构化提问支持 ACP form 模式；不声明 URL 模式或未实现的复杂嵌套表单能力。
- TUI 需支持动态主题通知并启用自动/系统主题；第三方程序已输出的显式 RGB 颜色仍由程序自身决定。
- 字体来自本机安装的字体，缺失字形使用系统回退，不下载远程字体。终端与文件预览保留独立的字体设置。
- Wiki 模型接口需兼容 OpenAI `/chat/completions`；图片模型需支持图片内容。模型结果继续经过人工审阅，请求重试不会增加 JSON 格式修复次数。
