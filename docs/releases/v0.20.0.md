# AgentBerth v0.20.0

- 笔记 Wiki 支持 PDF 导入（分片上传与 `raw/inbox` 自动采集）、自定义 Agent 历史与原生对话记录沉淀；页面与 Skill 编辑提供可渲染的 Markdown 预览。
- 活动栏图标补充文字标签，再次点击可折叠侧栏；设置与主题图标区分；插件配置支持本页浮窗修改。界面字号可在设置中整体缩放，并同步到插件视图。
- 项目、会话及已结束的运行记录支持删除后撤销，保留 30 分钟内最近 10 次删除的快照与日志。恢复保留原有运行顺序，不影响仍在运行的终端；连接旧后台时保留永久删除确认。
- 统一深浅色设计变量、表单、弹窗与提示反馈；快速切换支持模糊匹配、结果高亮和最近访问，加载时显示工作区骨架。
- 隔离会话历史和运行记录的加载状态，修复切换会话后旧响应关闭当前输出的问题；工作区订阅复用未变化的数据，减少无关重绘。
- 增加欢迎页操作、键盘快捷键面板、可键盘切换的侧栏与内容标签，以及 SSH 和筛选空状态的操作入口。
- ACP 与运行记录区分加载、离线和读取失败，提供重试；保留对话与草稿，隔离过期响应，重试读取不重放任务。
- Superagent 来源支持插件自定义管道字段、独立关键词规则和匹配逻辑；分发重试保留原配置，只重试失败的管道。
- 桌宠增加可切换的奶蛙（奶龙大笑）形象，首次选择时下载并校验素材，保留自定义动作与原有形象。
- 修复 ACP 输入就绪判断、终端查找时的尺寸变化，并加强 Windows 安装器进度、取消、升级及原生 Web 回归验证。

后台 API 55 / schema 9。schema 6–8 自动升级并保留项目、会话与任务数据，无需清除现有数据。当前架构的 API 44–54 后台仍可连接；删除撤销、界面字号等新增能力需要先停止运行中的会话并更新后台。撤销不恢复已停止的进程，也不重新执行命令。
