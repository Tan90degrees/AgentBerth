# AgentBerth v0.9.1 · Windows 安装体验修复

修复 [Issue #3](https://github.com/Tan90degrees/AgentBerth/issues/3)：安装缺少详细日志、没有百分比、疑似卡住且无法取消。

- 安装默认展开详情，文件准备显示实际字节百分比，随后明确显示校验、旧版清理、复制和完成阶段。
- 日志自动保存到 `%TEMP%\AgentBerth-setup-0.9.1-<进程号>.log`，包含版本、阶段、耗时、目录、进度和失败原因；完成页可选择打开日志。
- 安装和卸载不再启动 PowerShell/CIM 扫描。发现 AgentBerth 仍在运行时，提示从托盘退出，可选择重试或取消；不会强制停止会话。
- 新文件先在临时目录解压并逐文件校验 SHA-256，成功后才替换旧版。准备阶段可取消，保留现有程序及用户数据。校验、替换文件和登记阶段会短暂锁定取消，避免中途留下混合版本；旧版清理使用本次构建的卸载器，并设置 30 秒无输出超时。
- 固定兼容的归档过滤器，避免原生依赖文件被安装器静默漏解压；逐文件校验通过后才替换旧版。
- 清理旧版时使用 Windows 扩展长度路径，修复超过 260 字符的依赖文件导致升级失败；文件确实被占用时记录具体路径并恢复旧文件。
- 文件准备百分比固定显示在顶部，解压回调使用原生指令，避免与取消弹窗争用插件参数栈。
- 项目、会话和设置保持原有数据目录；安装异常时可将安装日志附到 Issue。

提供 Windows x64 安装 EXE、免安装 ZIP、SHA256SUMS.txt 和 build-info.json。构建信息同时记录桌面成品和安装器回归结果，两项均通过后才能发布。
