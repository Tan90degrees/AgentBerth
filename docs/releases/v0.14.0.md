# AgentBerth v0.14.0

可观察的远程 SSH 终端与 MCP。

- 远端只需要 SSH 服务和系统已有的登录 Shell，不安装 tmux、Bash、Python、Node 或常驻代理。沿用本机 OpenSSH 主机别名、密钥和跳板机。
- Agent 与用户共用同一个真实终端，目录、环境变量及交互程序在当前 SSH 连接中保持。POSIX Shell 使用内建命令识别完成及退出码；其他登录 Shell 可读屏、按键交互。
- 设置中复制随软件打包的 MCP 配置，无需另装本机 Node。支持执行命令、读屏、按键、有界等待和步骤分页；用户可随时接管。
- 主窗口关闭、MCP 超时或断开后，本机后台继续保持 SSH。链路真正断开后，旧任务结果标为 unknown；用户重新连接会建立新 Shell，不恢复或重放旧任务。
- 停止终端、托盘退出关闭本机 SSH。远端自行脱离 SSH 的任务可能继续运行，不能将关闭连接视为已确认停止全部远端进程。

首次使用前请在系统终端完成 SSH 密钥登录和主机密钥确认。安装后停止终端并在设置中更新后台以启用 API 21。第一版文件树、预览、Git 和资源统计仍用于本机项目。
