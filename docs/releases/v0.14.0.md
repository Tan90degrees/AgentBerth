# AgentBerth v0.14.0

可观察的远程 SSH 终端与 MCP。

- 远端只需要 SSH 服务和系统已有的登录 Shell，不安装 tmux、Bash、Python、Node 或常驻代理。沿用本机 OpenSSH 主机别名、密钥和跳板机。
- Agent 与用户共用同一个真实终端，目录、环境变量及交互程序在当前 SSH 连接中保持。POSIX Shell 使用内建命令识别完成及退出码；其他登录 Shell 可读屏、按键交互。
- 设置中复制随软件打包的 MCP 配置，无需另装本机 Node。支持执行命令、读屏、按键、有界等待和步骤分页；用户可随时接管。
- 主窗口关闭、MCP 超时或断开后，本机后台继续保持 SSH。链路真正断开后，旧任务结果标为 unknown；用户重新连接会建立新 Shell，不恢复或重放旧任务。
- 停止终端、托盘退出关闭本机 SSH。远端自行脱离 SSH 的任务可能继续运行，不能将关闭连接视为已确认停止全部远端进程。

首次使用在设置中保存 SSH 连接和登录信息；沿用系统 SSH 配置的高级模式需预先完成密钥登录和主机密钥确认。安装后停止终端并在设置中更新后台以启用 API 25。第一版文件树、预览、Git 和资源统计仍用于本机项目。

## SSH 连接与别名

- 设置中保存连接别名、地址、端口、用户名及密码 / 私钥口令 / 系统 SSH Agent 登录方式。
- Agent 可调用 `terminal_open` 按别名打开同一可见终端，后续工具直接使用别名；人工接管后不会自动夺回输入。
- 首次连接确认主机指纹；密码默认只保留在本次运行期间，可选择系统加密记住。服务器账号、地址均不预填，公开示例使用通用名称。
- 远端仍仅需 SSH 服务和已有 Shell；系统 SSH 配置入口保留对跳板机的兼容。

- SSH 启动过程立即显示在底部面板；等待凭据或握手期间也能取消，停止后可重新打开同一别名。

- 修复 SSH 状态栏与终端复用同一个 React key 导致切换后旧状态栏残留、重复增行。
- SSH 移到工作区底部可折叠面板，本机 Agent 与远端输出可同时观看；MCP 打开连接后自动展示，收起再展开保留同一终端。
- 连接按别名复用，重复和并发打开不创建额外会话；面板内提供连接选择、实时步骤及会话操作。

- SSH 面板独立新建和管理 SSH 会话，不再从普通项目会话表单选择运行位置；无需先添加本机项目。SSH 编辑与复制也使用专用表单。

- 常规 SSH 入口只填写服务器信息；Agent 通过 MCP 管理命名会话、关闭、改名、删除和明确重连，人工接管仍优先。
- 新增同一 SSH 登录连接上的 SFTP 上传、下载、目录递归、前缀核验续传与服务器间流式传输；后台任务去重、进度、等待和取消均可见。默认不覆盖，不转发 SSH Agent，无远端运行时依赖。
- 已确认的命令包装回显替换为原始命令，桌面、MCP 读屏与保存画面统一生效；保留退出码、目录跟踪和实际程序输出。
