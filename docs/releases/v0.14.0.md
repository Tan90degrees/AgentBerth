# AgentBerth · 泊栈 v0.14.0

新增可观察的远程持久终端：让 Agent 操作你正在看的真实终端，随时人工接管。

- 新建会话选择“远程 SSH”，使用已有 OpenSSH 配置连接 Linux Bash/tmux。同一 Shell 保留目录、环境变量和前台程序，断线恢复原会话。
- 设置中一键复制 MCP 配置和给 Agent 的说明。支持命令、真实画面读屏、交互按键、长任务有界等待和操作步骤分页。
- 顶部紧凑显示远端状态，点击“交给 Agent / 接管”切换输入权；客户端退出和工具超时不停止任务。
- 命令 ID 防止重放，不确定结果明确显示；步骤默认折叠，终端尺寸仍由桌面统一管理。
- 关闭主窗口继续运行；停止终端和托盘退出确认结束远端 tmux 会话。远端不可达时会明确报告无法确认停止。

首次使用前请确认系统终端可以免交互登录，远端已安装 Bash 和 tmux。安装后在设置中更新后台以启用 API 20。第一版文件树、预览、Git 和资源统计仍用于本机项目；不包含断线期间完整 TUI 录像。

使用说明：docs/remote-terminals.md；Agent 指南：docs/remote-terminal-agent.md。

Windows 下载：`AgentBerth-0.14.0-windows-x64-setup.exe` 或 `AgentBerth-0.14.0-windows-x64.zip`。
