# AgentBerth v0.14.0

可观察的远程 SSH 终端与 MCP。

- 设置页面改为分类导航、全局搜索和统一选项布局，支持中英文关键词与键盘切换。底部集中保存启动/资源设置，未保存项可单独重置，分类切换保留草稿，保存时自动定位隐藏的无效字段；主题与预览字体即时保存。

- 未查看的终端收到新输出时显示“新输出”标签，支持本机会话、收拢项目和 SSH 面板/会话选择；切回可见终端自动清除，历史、预览、设置及后台窗口不会误清除。提醒只记录实时输出，不将恢复画面当成新消息。标签使用淡色底且不闪烁，与运行状态绿点区分。

- 历史来源文件与读取诊断集中到顶部默认收起的“读取详情”；重复提示合并，已知英文诊断提供中文说明，多会话选择与内容不完整保留简短提示，不再堆在对话底部。

- 远端只需要 SSH 服务和系统已有的登录 Shell，不安装 tmux、Bash、Python、Node 或常驻代理。沿用本机 OpenSSH 主机别名、密钥和跳板机。
- Agent 与用户共用同一个真实终端，目录、环境变量及交互程序在当前 SSH 连接中保持。POSIX Shell 使用内建命令识别完成及退出码；其他登录 Shell 可读屏、按键交互。
- 全局设置可分别调整本机终端和 SSH 会话上限（默认各 16，范围 1–128）。两类独立计数，连接中的 SSH 只占一个名额；保存立即应用，调低上限不停止已有会话。顶部显示各自占用和限额。
- 普通命令一次调用返回状态、退出码和命令输出；长任务支持按游标事件式读取新增日志，明确提示缓存截断。TUI 仍按需读屏，移除读屏时额外的历史序列化。后台提供请求/命令耗时，便于定位延迟。
- 设置中复制随软件打包的 MCP 配置，无需另装本机 Node。支持执行命令、读屏、按键、有界等待和步骤分页；用户可随时接管。
- 主窗口关闭、MCP 超时或断开后，本机后台继续保持 SSH。链路真正断开后，旧任务结果标为 unknown；用户重新连接会建立新 Shell，不恢复或重放旧任务。
- 停止终端、托盘退出关闭本机 SSH。远端自行脱离 SSH 的任务可能继续运行，不能将关闭连接视为已确认停止全部远端进程。

首次使用在设置中保存 SSH 连接和登录信息；沿用系统 SSH 配置的高级模式需预先完成密钥登录和主机密钥确认。安装后停止终端并在设置中更新后台以启用 API 31。第一版文件树、预览、Git 和资源统计仍用于本机项目。

## SSH 连接与别名

- 设置中保存连接别名、地址、端口、用户名及密码 / 私钥口令 / 系统 SSH Agent 登录方式。
- Agent 可调用 `terminal_open` 按别名打开同一可见终端，后续工具直接使用别名；人工接管后不会自动夺回输入。
- 首次连接确认主机指纹；密码默认只保留在本次运行期间，可选择系统加密记住。服务器账号、地址均不预填，公开示例使用通用名称。
- 远端仍仅需 SSH 服务和已有 Shell；系统 SSH 配置入口保留对跳板机的兼容。

- SSH 启动过程立即显示在底部面板；等待凭据或握手期间也能取消，停止后可重新打开同一别名。

- 修复 SSH 状态栏与终端复用同一个 React key 导致切换后旧状态栏残留、重复增行。
- SSH 移到工作区底部可折叠面板，本机 Agent 与远端输出可同时观看；MCP 打开连接后自动展示，收起再展开保留同一终端。
- 连接按别名复用，重复和并发打开不创建额外会话；面板内提供连接选择、实时步骤及会话操作。

- SSH 面板独立新建和管理 SSH 会话，不再从普通项目会话表单选择运行位置；无需先添加本机项目。SSH 编辑与复制也使用专用表单。

- 常规 SSH 入口只填写服务器信息；Agent 通过 MCP 管理命名会话、关闭、改名、删除和明确重连，人工接管仍优先。
- 新增同一 SSH 登录连接上的 SFTP 上传、下载、目录递归、前缀核验续传与服务器间流式传输；后台任务去重、进度、等待和取消均可见。默认不覆盖，不转发 SSH Agent，无远端运行时依赖。
- 已确认的命令包装回显替换为原始命令，桌面、MCP 读屏与保存画面统一生效；保留退出码、目录跟踪和实际程序输出。


### 共享终端交互优化

- 普通命令只需 alias 和 command；requestId 可选并自动生成，显式重试仍须复用同一 ID。错误指出参数字段，只有确认后台版本过旧才提示更新，不自动换执行方式重放。
- 文本按键默认附带 Enter，显式 enter=false 才不提交；支持多行命令和 Tab。普通命令默认最多等 5 秒，完成立即返回；首段输出最多合并等待 75 ms，流式命令不等满上限。
- 命令结果与人看的终端画面独立，每条本机临时缓存从 128K 提高到 8M 字符，与模型上下文分开；默认输出对齐 ssh-skill：256 KiB、4000 行、64 KiB 尾部，完整 JSON 结果上限 256 KiB。超限保留首尾和总量，不自动读完分页；仅任务需要时显式 mode=page，每页默认 32K、最高 64K 字符。无需 clear 取回日志。
- SSH 面板上边缘支持拖动高度、方向键微调、双击复位与本机保存，拖动期间不重新挂载终端。


### 防止长列表被误认为只剩下半部分

- 读屏明确标注仅为可见视口，并提供对应命令的可选有界摘要入口；命令结果明确标注范围、总量、预算省略和真实缓存丢失。continuation 仅用于运行中的新增输出，完成后不自动读完缓存。
- 已确认空闲的 POSIX Shell 中，通过文本加回车提交的命令也自动捕获本轮输出；交互输入保持原样。可省略 actionId 从头读取最近可靠关联的命令，后续页必须明确 ID，防止与其他命令混淆。
- 5 行终端中的 120 行小列表在默认预算内仍能从原结果完整读回并保持顺序，命令只执行一次；6000 行日志则保留首尾，不自动读完明细。无需重跑或 clear；更新后台至 API 31 并重连 MCP。
