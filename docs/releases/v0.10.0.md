# AgentBerth v0.10.0 · 项目文件与预览

工作台新增可收起的文件面板，在运行终端的同时浏览项目文件。

- 懒加载目录树、文件分页、键盘导航、刷新与可调宽度。
- Git 忽略内容灰显，支持一键隐藏；使用 Git 实际规则处理嵌套排除、例外和已跟踪文件。
- 代码预览带行号、语法高亮、复制与刷新。高亮在 Worker 中执行，兼容深色和浅色外观。
- Markdown 可在源码和渲染之间切换，支持表格、任务列表、高亮代码块、本地图片与项目内链接。
- 支持 UTF-8 / UTF-16 文本和常见图片，明确显示空文件、二进制文件及截断状态。

文件浏览为只读操作，不影响现有项目、会话和终端。文本预览上限 256 KiB / 10,000 行，图片上限 4 MiB；路径限制在当前项目内。Markdown 不执行 HTML 或脚本，远端图片显示为网页链接。详见[文件浏览与预览](../files.md)。

旧后台需要先停止全部终端，再在设置中更新后台，才能使用文件浏览接口。数据格式保持兼容。
