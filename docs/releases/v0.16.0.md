# AgentBerth v0.16.0

完善用户已有 Claude Code、OpenCode 的适配，不捆绑或安装 Agent 本体，不代配模型与账号。

- 桌宠设置新增「安装/更新适配」，支持项目和用户范围。Claude 合并已有 hook；OpenCode 自动识别 1.x / 2.x 并部署对应的无外部依赖插件。配置有变更时备份，重复安装去重。
- 桌宠提高置顶层级，显示、恢复和失焦时保持窗口顺序，并关闭该透明窗口的后台渲染节流，减少其他程序弹窗时被遮住或停止绘制的问题；不抢占输入焦点，保留取消置顶与隐藏。
- OpenCode 桌宠根据真实事件显示工作、授权/问题等待、完成、失败，忽略子会话完成。应用内教程可复制给 Agent 自动配置。普通终端和 SSH 仍不展示。
- OpenCode 2.x 适配使用独立服务继承当前终端身份；保留用户配置与历史。自定义包装命令需转发 `--standalone`，共享 `--server` 不参与桌宠绑定。
- Hook 携带原生 ID，按项目、类型、当前运行精确关联；支持同一终端内的新对话，手动关联/解除优先。
- OpenCode 首次元数据查询暂时失败时，后续同一会话事件可恢复绑定，无需再提交一次输入；子会话及无关后台事件不会抢占当前会话。
- OpenCode 支持通过官方 CLI 发现多条本机历史、搜索、分页、预览、刷新及恢复；兼容两代导出格式，启动 TUI 时不额外查询历史，也不轮询私有数据库。CLI 缺失、超时或空输出时明确报错，可改用手动导出 JSON。
- 自定义配置和脚本可声明 `integration: "claude"` 或 `"opencode"`，继承原生历史与 Skill 管理，仍可用专有插件覆盖具体能力；已有插件热更新和导入流程不变。
- SSH harness 要求在整个任务完成、最终答复前由 Agent 主动 dispose，一次关闭并删除自己的临时记录；有长任务、传输或未知结果时保留并报告标识。没有定时/空闲回收；keepHistory:true 可主动关闭并保留记录，后台预检避免误关。
- MCP 设置提供 OpenCode 专用配置格式；Skills 遵循 `CLAUDE_CONFIG_DIR`、`XDG_CONFIG_HOME`。

工作台后台 API 更新为 39，四工具 MCP 最低为 API 39。升级后先在设置中更新空闲后台，再安装适配并重新启动对应 Agent 会话。正在运行的任务不会因安装适配被自动重启。
