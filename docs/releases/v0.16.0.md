# AgentBerth v0.16.0

新增软件内更新。设置 → 关于 → 软件更新支持检查、后台下载、取消和一键应用；更新就绪时顶部也会显示更新入口。

应用代码更新后自动重载界面，恢复窗口布局与项目选择，重新连接原后台。运行中的本地终端和 SSH 不会因应用更新而停止。后台代码会在全部终端结束后自动更新。更新包经过 SHA-256 和逐文件校验，新界面启动失败会回退。

首次需要安装本版本以启用更新启动器；之后兼容当前 Electron 运行环境的版本可以直接在软件内更新。Electron 运行环境变化时仍需完整安装包。托盘退出仍会停止所有终端。

同时包含 SSH 控制权修复：Agent 断开、重连或命令完成都不会主动将终端交回用户，只有用户明确接管才会改变控制权。
