# AgentBerth · 泊栈 v0.13.2

本次补齐 Git 远端分支查看和切换。

- Git 侧栏“分支与远端”内切换本地/远端列表，支持名称筛选；点击“获取远端”更新列表。
- 选中远端分支后，复用已有本地跟踪分支或创建并切换到新的跟踪分支，可调整本地名称。
- 保留未提交改动及本地提交，同名分支跟踪关系不符时提示换名；不强制覆盖。
- 支持多远端与自定义 fetch 映射，清理已删除的远端跟踪引用。
- 可在终端运行期间操作，保留 PTY/PID 和输入输出。旧后台需在设置中更新后启用远端分支功能。

Windows 下载：`AgentBerth-0.13.2-windows-x64-setup.exe` 或 `AgentBerth-0.13.2-windows-x64.zip`。
