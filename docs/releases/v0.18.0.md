# AgentBerth v0.18.0

- 新增 ACP v1 接入，复用本机已有 Agent 和登录。左侧管理会话，主区显示流式对话、计划、工具和授权；按实际能力提供模型、模式、登录与原生恢复。
- 新增可启停的 Superagent 插件：选择 ACP 协调/执行 Agent，任务独立会话和可选 Worktree，审计、人工确认与显式中断恢复。
- 信息源完全由插件注册，不捆绑 GitHub 或飞书。提供绑定规则、身份准入、事件去重、人工审核回传及本地开发示例。
- 插件安装改为分块解压，支持 80 MiB 包；默认 ZIP 上限 256 MiB、展开 1 GiB、50000 个条目。仍需 AgentBerth 清单，不承诺 DeepSeek Harness 宿主 API 通用。
- 开发套件包含 ACP / Superagent 来源指南；另提供可修改的独立 Superagent 插件包。

后台 API 44。ACP 与 CLI 两种接入并存；未捆绑开箱即用 Agent。会话断开或结果未知时不会自动重放任务。该版本沿用当前 schema 7 数据；更早架构仍按原发行说明处理。
