# AgentBerth v0.18.0

- 新增 ACP v1 接入，复用本机已有 Agent 和登录。左侧管理会话，主区显示流式对话、计划、工具和授权；按实际能力提供模型、模式、登录与原生恢复。
- 新增可启停的 Superagent 插件：选择 ACP 协调/执行 Agent，任务独立会话和可选 Worktree，审计、人工确认与显式中断恢复。
- 信息源完全由插件注册，不捆绑 GitHub 或飞书。提供绑定规则、身份准入、事件去重、人工审核回传及本地开发示例。
- 插件安装改为分块解压，支持 80 MiB 包；默认 ZIP 上限 256 MiB、展开 1 GiB、50000 个条目。仍需 AgentBerth 清单，不承诺 DeepSeek Harness 宿主 API 通用。
- 开发套件包含 ACP / Superagent 来源指南；另提供可修改的独立 Superagent 插件包。

后台 API 50。ACP 与 CLI 两种接入并存；未捆绑开箱即用 Agent。会话断开或结果未知时不会自动重放任务。该版本沿用当前 schema 7 数据；更早架构仍按原发行说明处理。

- 验证真实 OpenCode 1.19.5 的模型、plan 模式与原生会话恢复；优先使用标准配置项模式接口，继续支持早期 `modes`。测试用 CLI 不包含在发行软件包。


Superagent 任务页集中接收问题回答与后续指令。「发送并继续」延续当前协调/执行阶段；关联会话提供查看、授权和返回任务入口。桌宠区分等待回答、会话授权与验收。协调报告支持正文包围的 JSON，格式无效时明确请求人工处理。命令和参数卡片支持高亮、复制；文件修改显示增删统计与行号。


Superagent 独立任务工作区：内部会话从普通列表与快速切换隔离，在任务内查看 ACP 过程、处理授权、管理内部历史。运行期间可排队补充要求、撤回，或请求停止本轮并优先插话；持久队列去重，中断后不自动重放。ask 支持单选、多选和自定义回答卡片；对话进展、底部固定输入框、阶段指示和元数据折叠统一重做，深浅色控件与滚动条同步。后台 API 50。


来源请求新增待批准收件箱、直接批准/拒绝、失效项目或 Agent 的审批前修正，以及侧栏待办数量。来源配置与日常处理分开，开发/调试记录折叠。任务支持搜索、筛选、分页和显式删除；运行中明确取消后删除，保留工作区及来源去重标识。可选回复明确显示接收渠道、发起人和内容，确认后才发送；批准或验收不自动通知渠道。

Superagent 改为任务看板和命名来源管道：按状态分组卡片，显示项目、当前 Agent、最近活动与阻塞原因；详情显示实时执行状态、授权入口和最近工具摘要。来源可按会话或人员区分、多组路由到不同项目，独立保存/启停/编辑/删除并查看回执；支持多来源汇入和多管道分发，各管道固定独立 Worktree，同管道串行执行，任务按管道筛选。修复任务菜单随切换残留，确认动作绑定原任务。此前的一来源一配置自动保留为管道，schema 7 不变。API 44–49 后台可暂时保留连接，停止当前运行后从应用提示更新空闲后台以加载新能力。

看板与列表支持多选、选择当前页、批量批准/拒绝/删除；执行前预览，运行中删除明确停止，逐项反馈，失败项保留选中且不自动重试。任务/ACP/CLI 对话向上滚动自动加载更早消息并保持阅读位置。

修复 ACP 进程退出与输出流读取之间的竞态：停止接受新输入后，先接收已经到达的完整协议消息，再清理连接，保留退出前的尾部输出；继承输出流未关闭时有界结束并标记未知结果。

来源管道支持多对多订阅：每个来源独立选择接收会话，同一事件可进入多条命名管道。接收记录显示逐管道结果，失败分发以原事件 ID 重试，成功分发不重放；首次接收后新增的管道不补收旧消息。管道首次运行建立固定 Git Worktree，协调与执行使用同一目录，同管道等待回答/授权/验收期间保持串行，不同管道并行。看板和列表按管道筛选，新建任务可指定管道。旧任务保留原目录，非 Git 隔离副本支持扫描确认、排除规则与容量、进度/取消、差异预览、选择应用、冲突检查、导出和保留副本清理。

开发指南与工具统一进入所属插件配置，Superagent 工作台通过“设置”打开自身配置；移除全局与桌宠菜单的重复指南入口。工作台图标使用居中 SVG，精简插件、设置和任务页面的说明文案。

后台 API 50：非 Git 管道采用持久隔离副本，扫描确认后建立。支持复制规则与容量、进度/取消、差异预览、选择应用、冲突检查、导出、重建和保留副本清理。ACP 与文件预览绑定隔离目录，原项目仅在明确应用时更新。修复新来源注册后已打开表单未及时刷新。
