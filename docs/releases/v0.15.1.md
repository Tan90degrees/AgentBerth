# AgentBerth v0.15.1

优化 SSH 文件上传速度。

- 上传使用有上限的并行分块写入，单个文件最多同时发送 32 个小块，约 1 MiB 数据在途，减少每个数据包等待服务器确认造成的停顿。
- 只有全部写入得到确认后才报告文件完成；失败、取消后停止发送新块，迟到的确认不会重新启动上传。
- 沿用已有 SSH 登录连接、MCP 文件传输接口、显式覆盖和前缀核验续传。用户无需增加配置，远端仍只需 SSH/SFTP 服务。
- 提升主要针对有网络延迟的文件上传；目录内文件仍逐个处理，实际速度受带宽、服务器和磁盘性能影响。

## 安装与升级

Windows 提供安装 EXE、免安装 ZIP、`SHA256SUMS.txt` 和 `build-info.json`。升级前保存工作并从托盘退出旧程序；安装后在设置中更新空闲后台以加载上传优化。工作台 API 仍为 35，四工具 MCP 继续兼容 API 34。

并行上传中断后可能留下不完整的文件；续传仍会核对已有文件前缀，不匹配时需要确认后显式覆盖。
