# AgentBerth v0.21.0

## 主要改进

- 修复 Superagent 中断与退出清理：先保存检查点并停止调度，再关闭 ACP；退出期间保留停止与重试退出，任务内部会话不再由工作区自动重开。
- 中断任务直接提供重新协调、重试停止与确认结束。确认完成仅接收已交付的待验收结果，未知结果的手动结束保留未验收标记；清理失败不会提前完成任务，旧版中断记录也可恢复操作。
- 项目折叠状态跨重启保留，活动栏可排序，文件/Git 使用独立可调宽度的右侧栏；完善导航、焦点和 DeepSeek Harness 进程资源统计。
- 会话回复、恢复结果、后台更新与插件反馈统一进入右上角「通知与告警」，新通知展开 5 秒后收起；修复原生 Web 遮挡弹层及窄窗口工具栏溢出。
- Wiki 完整导入会话与长素材，同次 Markdown/文本/PDF/图片组成一份素材与提案；补齐回收站、审阅记录删除、自动采集/沉淀，改善流式及提案 JSON 解析。
- 主题切换同步本机/SSH 的颜色查询与动态通知；Windows 使用随应用提供的 ConPTY 运行库，修复管道故障和输出线程遗留，保留进程、输入及终端尺寸。
- 新增并持续维护仓库 AGENTS.md，明确进程、插件、界面文案、长素材及验证交付约定。

## 安装与升级

- Windows x64 安装版：`AgentBerth-0.21.0-windows-x64-setup.exe`。
- Windows x64 免安装版：`AgentBerth-0.21.0-windows-x64.zip`，完整解压后运行 `AgentBerth.exe`。
- 发布页提供 `SHA256SUMS.txt` 与 `build-info.json`，用于核对文件、提交及构建验证结果。
- 后台 API 62 / schema 9。由 v0.20.0 升级无需清空数据目录；schema 6–8 自动升级，当前架构的 API 44–61 后台仍可连接。使用新增后台能力前，停止会话后更新后台，或从托盘完整退出旧版后重新打开。
- 保留项目、会话、插件配置与 Wiki 素材；退出后恢复的是重新启动或续接的会话，不保留原进程内存，也不重放历史输入。

## 中断任务的处理

- 旧版留下的“连接清理尚未完成”任务会提供重试停止。清理完成后，可明确重新协调一次新尝试，或确认结束并保留结果未验收状态。
- 只有执行器已交付且等待验收的结果可确认完成；停止失败时保留任务及清理入口，取消后也仍可重试清理。
- 重开程序不自动重发任务或重新连接任务托管的 ACP 会话；队列和原有记录继续保留。显式结束会撤回未发送指令。

## 使用范围

- TUI 自身需选择自动/系统主题，并支持动态主题通知；固定主题或不处理通知的 CLI 仍由其自身设置控制。
- 同次 Wiki 混合导入默认生成一份素材与提案；模型结果仍需审阅，未配置模型时保存原始素材。
