# AgentBerth v0.15.2

修复 SSH 终端偶发自动切到人工控制的问题，并支持多个 Agent 独立管理 SSH。

- 不同 Agent 按保存的服务器信息建立独立连接，同一别名或会话名称不会共用终端。首次 open/create 可由程序自动分配唯一 agentId，共享一个 MCP 的 subagent 后续带回自己的 ID，连接、输入、目标记忆、续取和取消互相隔离。
- Agent 只列自己的会话；任务完成可用 terminal_session(action=dispose) 一次关闭该上下文创建的全部 SSH，保留运行记录。用户仍可在桌面查看全部终端并主动接管。
- 生命周期规则内置于工具说明，用户只填写服务器信息，无需额外复制提示词。

- MCP 客户端断开时只释放它的单写入占用，不撤销已有 Agent 授权；已提交的命令继续运行，重新连接 MCP 后可继续查询结果和操作同一终端。
- 同一运行实例中的 SSH 断线、重连、命令完成和等待超时都不会自动交回用户。连接状态与控制权分别维护，迟到的状态更新不能覆盖用户的选择。
- 只有用户主动点击“接管”才将 Agent 终端切回人工控制；接管后立即拒绝 Agent 输入，直到用户再次点击“交给 Agent”。MCP 工具不提供交回或更改控制权的入口。
- 保持单写入者、运行实例校验、请求去重及结果未知规则；SSH 重连仍建立新 Shell，不恢复或重放旧任务。

## 安装与升级

Windows 提供安装 EXE、免安装 ZIP、`SHA256SUMS.txt` 和 `build-info.json`。升级前保存工作并从托盘退出旧程序；安装后在设置中更新空闲后台以加载修复。工作台需要 API 37（注入桌宠会话标识）；当前四工具 MCP 最低仍为 API 36；旧后台会明确提示更新，不降级到全局共享会话。

停止并重新启动终端、或重启整个后台会建立新的运行实例；已有命令不能因此恢复或自动重放。

## 桌宠

设置新增可选桌宠：独立透明窗口、切换多个会话、返回对应终端、置顶和大小调整；内置六种 GIF，可按状态自定义。Agent hook 通过本机鉴权接口报告执行、等待、完成和失败；提供 Claude Code 配置，私有 TUI 可调用通用脚本。未接入、断线和过期状态明确标识。新启动本机会话继承绑定 ID，已有终端需重新启动。详见 [桌宠接入文档](../desktop-pet.md)。

默认形象升级为 dsh-pet 的 MIT 授权 Q 版角色，按状态播放完整动作；使用带半透明边缘的 24 fps 动画，设置页默认静态、悬停预览。已有自定义 GIF 保留，点击对应状态“恢复默认”即可使用新形象。来源和许可证随软件打包。
