# AgentBerth v0.15.0

会话恢复、插件式 Skill 管理与多文件预览。

## 会话恢复

- 新启动的 Codex、Claude Code 会话在运行期间及退出时发现并关联原生会话 ID，刷新最终历史，避免新会话误用上一次的恢复入口。
- 自定义 Agent 复用已有插件的会话列表、历史读取与恢复接口，无需另外接入。
- 手动关联优先；多个新会话、同时运行或插件列表不完整时保留手动选择，不猜测绑定。

## Skill 管理

- 在设置的 Skills 分类中，按 Agent、项目或用户范围查找、导入、编辑、启用、停用及移除 Skill。
- Skill 能力复用现有 Agent 配置、清单或自描述脚本及热更新机制；插件只需声明可选的 `skills.project` / `skills.user` 目录，无需再安装一种插件。
- 导入保留完整 Skill 文件夹及资源；停用移出加载目录，移除保留到相邻恢复目录。实际加载与热更新由对应 Agent CLI 决定。

## 文件预览与终端导航

- 最多打开 20 个文件预览标签，切换时保留各文件的预览状态，按项目恢复已打开的文件路径。
- 支持关闭按钮、鼠标中键和标签栏内 Ctrl/⌘+W 关闭标签；关闭当前文件后切换到相邻文件，关闭后台标签不切换当前预览。
- Git 差异与工作区视图切换保留预览和终端实例。
- 终端路径定位请求只处理一次，关闭候选框后切换项目或会话不会再次弹出旧请求。
- 文件路径需按住当前窗口内按下的 Ctrl（macOS 为 ⌘）才能点击；窗口失焦后清除修饰键状态，避免普通点击误触发。

## 安装与升级

- Windows 提供安装 EXE 和免安装 ZIP，并附带 `SHA256SUMS.txt` 与 `build-info.json`。
- 升级前先保存工作并从托盘退出旧程序；安装后在设置中更新空闲后台，以启用工作台 API 35。
- 四工具 MCP 继续兼容 API 34；已有 Agent 插件不声明 Skill 目录也可继续使用。

## 已知限制

- 原生历史发现有扫描范围和数量上限；OpenCode 或未提供会话列表/历史接口的私有 TUI 仍需手动关联或导入。
- 并发或不明确的会话候选不会自动关联，终端画面不能用于推断私有 TUI 的内部会话 ID。
- 文件预览为只读；Skill 是否被即时加载取决于对应 CLI 的行为。
