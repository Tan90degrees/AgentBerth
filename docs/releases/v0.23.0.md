# AgentBerth v0.23.0

## 桌宠远程资源监控

- 在「插件中心 → 桌宠 → 配置 → 远程资源监控」选择最多三个已保存的 SSH 节点，并排查看 CPU、内存和各张 NVIDIA GPU 或昇腾 NPU 的利用率、已用及总显存、温度，无需滚动。
- 通过配置或桌宠右键菜单独立开关「显示远程资源」。关闭面板时暂停采集并保留节点与显示设置。字号可设为 9–16 px（默认 10 px），刷新间隔可设为 1–300 秒（默认 20 秒）。
- 桌宠 Agent 会话列表会移除已退出的会话。节点采集失败时会标记旧样本，同一节点仍在采集时跳过本轮。
- 主机 CPU 和内存由远端 Linux 提供。逐卡采集依赖远端的 `nvidia-smi` 或 `npu-smi`，首次使用前请在 SSH 设置确认对应的主机指纹。详见 [桌宠使用指南](../desktop-pet.md)。

## Pi、Wiki 与 Superagent

- 本机新建会话时可选择内置 Pi 终端，沿用本机 Pi 模型和登录，支持历史、原生恢复、Wiki 会话沉淀与桌宠。Pi ACP 需单独安装适配器并测试连接，协调与执行能力以适配器实际协商结果为准。详见 [Pi 终端](../agent-plugins.md) 和 [Pi ACP](../ACP_SUPERAGENT.md)。
- 在 Wiki「新增原始素材」上传一份保留层级的 ZIP，或单个 Markdown、UTF-8 文本、PDF、图片文件。原件可按目录预览、下载和引用。编译让模型选择阅读顺序，目录请求重复或选错文件时继续处理未读材料，最后为整组生成一份待审阅提案。
- Wiki「任务」支持筛选、取消、重试，以及删除或清空已结束记录，保留已保存的素材、提案和页面。详见 [Wiki 使用指南](../NOTES_WIKI.md)。
- Superagent 交付文件可直接预览，受管工具限制隐式 Shell 和越界文件操作。信息源管道可配置向原消息回传状态，模型摘要需经用户确认。外观套件更新配色并同步原生标题栏。详见 [ACP 与 Superagent](../ACP_SUPERAGENT.md)。

## 安装与升级

- Windows x64 安装版 `AgentBerth-0.23.0-windows-x64-setup.exe`。
- Windows x64 免安装版 `AgentBerth-0.23.0-windows-x64.zip`，完整解压后运行 `AgentBerth.exe`。
- 发布页提供 `SHA256SUMS.txt` 和 `build-info.json`，可核对哈希、提交及 Windows 安装和打包验证结果。
- 后台 API 67 / schema 9。从 v0.22.x 升级保留项目、会话、插件配置与 Wiki 数据。现有架构的 API 44–66 仍可连接。使用 Pi 和完整远程资源指标前请结束活跃会话并更新后台，或从托盘完整退出旧版再启动新版。
