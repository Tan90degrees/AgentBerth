# AgentBerth v0.9.0 · 多会话历史

- 终端运行中也能关联、切换或解除原生会话 ID。仅更新工作台历史和下次恢复目标，当前 CLI、PTY、命令与 PID 保持不变。
- 同项目、同 Agent 类型保留多条历史，按标题/ID 搜索，每页 5/10/20 条，支持翻页、预览及按 ID 刷新。点选只预览，点击关联才更新目标。
- 解除关联保留历史及原文件；0.8 的现有历史自动迁移。每个工作台会话独立关联一个 ID，同项目下共享多条候选历史。
- 插件增加可选 list 接口：项目范围、多 ID、游标分页、搜索和轻量元数据。旧版 history/resume 插件兼容，单脚本导入和开发指南同步更新。

内置 Codex/Claude/OpenCode 列出已导入或手工关联的记录；自动发现由提供 list 的插件实现。记录仍为只读文本视图，保留容量与原生格式限制。

下载 Windows x64 安装包或完整解压 ZIP。升级前从托盘退出旧版本；需要时在设置中更新后台以启用 API 11，旧后台保留终端访问但不提供新列表功能。
