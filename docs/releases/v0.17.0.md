# AgentBerth v0.17.0

工作台改为 Cordis 插件架构，后台 API 41。安装后默认保留现有功能与数据，不附带 Agent 引擎。

- **设置 → 插件**：安装 ZIP、加载开发目录、实时配置、启用、停用、卸载及重新加载。内置 SSH/MCP、桌宠、文件、Git、资源、项目/终端与 Agent 接入统一管理。
- Agent 与 Skills 在同一插件注册。支持自定义 MCP 命令、HTML 视图和 Electron 桌面入口；应用内可导出可直接修改的模板、完整开发指令及指南。
- 依赖按序装配，停用时撤销接口并释放资源。开发修改自动重载；失败保留旧后台版本。运行中的终端/命令等会阻止相关插件被误卸载，无关插件可以独立操作。
- 卸载保留配置、插件数据与既有会话；外部包需重新选择才能安装，开发源目录永不删除。原有单文件 Agent 配置/脚本继续兼容。

升级后在空闲时更新后台以启用插件管理。插件是可信的本机代码，请仅安装可信来源；HTML 视图隔离不等同于 Node 插件沙箱。使用 Cordis 框架不代表直接兼容 DeepSeek Harness 的业务插件；私有 TUI 的精确状态仍需可用的事件源/适配器。
