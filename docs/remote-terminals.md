# 可观察的远程终端与 MCP

AgentBerth 将同一个远端 tmux 会话同时交给 Agent 操作、给人观看。终端保持真实的交互界面，而不是把一次性 SSH 命令结果拼成日志。命令持续使用同一 Shell 的目录、环境变量和虚拟环境。

## 开始使用

1. 在系统终端配置 OpenSSH 主机别名，例如 `ascend-dev`，确保 `ssh ascend-dev` 能用密钥或 SSH Agent 成功登录。首次连接的主机密钥须在系统终端确认。支持系统 SSH 配置中的端口、IdentityFile 和 ProxyJump；不会复制或向模型发送私钥。
2. 远端 Linux 需要 Bash、tmux 和常用的 base64/tr 工具。第一版不支持远端 Windows，也不弹出 SSH 密码/交互式 MFA 窗口。
3. 在 AgentBerth 左侧项目上右键 → 新建会话 → 运行位置选择 **远程 SSH · 持久终端**。选择自动发现的主机别名，填写远端绝对工作目录，创建并启动。也可手动输入尚未被列表识别的主机别名。
4. 打开 **设置 → Agent 远程终端 · MCP → 复制 MCP 配置**，加入 Agent 客户端的 MCP 配置。复制的 JSON 包含本机 Electron 路径、打包好的 MCP 程序和数据目录，以及 `ELECTRON_RUN_AS_NODE=1`，不需要额外安装 Node.js 或 npm 包。不同客户端可能使用 JSON 或 TOML；保留 command、args、env 三项即可。
5. 回到终端点击 **交给 Agent**。让 Agent 使用 `terminal_list` 选择该会话，再通过终端工具进行远程工作。Agent 操作时人工输入被禁用，仍可滚动、选中、复制和查找。点击 **接管** 即刻收回输入权；当前命令继续运行，不会自动发送 Ctrl+C。

项目仍是本机的分组与工作目录。第一版的左侧文件树、预览、Git 和资源统计仍用于本机，不会将远端路径误当成本机文件。远程会话以 SSH 标记显示，暂不采集远端 CPU/内存。

## 长任务与交互程序

`terminal_execute` 将一条命令送入已确认空闲的 Bash。其 requestId 是调用者生成的 UUID；同一操作重试必须复用 requestId，不会再次执行。返回的 actionId 用于 `terminal_wait`。命令退出由 Bash 钩子提供真实退出码，不能从屏幕安静、出现某个 `$` 字符或超时推断完成。

等待在后台由事件触发，单次最长 30 秒。工具返回 `running` 后仍是同一任务，不应重新启动命令。客户端若无法在后台事件到达时自动唤醒模型，仍需继续有界等待；第一版不声称所有 MCP 客户端都能零轮询自动续跑。读屏工具返回当前屏幕文字、光标、行列和连接状态，不将整个 ANSI 流灌入模型上下文。

对于 vim、top 等 TUI，使用 `terminal_screen` 和 `terminal_keys`，而不是新开 SSH 执行另一个命令。`Ctrl+C` 明确中断前台任务。若接回的 Shell 状态为 unknown，先读屏确认；只有确认为提示符时才显式发送 Enter 以重新识别提示符，后台不会擅自替你发送按键。

## 断线、关闭与停止

- 主窗口关闭、收起终端、MCP 工具超时：任务继续运行。
- MCP 客户端退出：释放输入权给人；已提交命令继续运行。
- SSH 断线：远端 tmux 保留进程，后台按退避策略重连原会话，不重放命令，也不会在原会话消失后偷偷创建一个新 Shell。
- AgentBerth 后台崩溃：远端 tmux 仍可存在。再次启动该会话会复用相同的远端会话标识。旧操作结果显示 unknown，不虚构退出码。连接失败后也应先恢复同一个会话，避免另建任务重复执行。
- 左侧“停止终端”和托盘“退出”：确认销毁对应远端 tmux 会话后才完成。若远端不可达，无法保证已停止，会显示失败并保留后台供重试。需要用户自行确认的脱离会话子进程（例如 nohup、其他 systemd 服务）不属于 tmux 的前台进程树。

远端使用独立的 `tmux -L agentberth -f /dev/null` 服务，名称为 `ab-<sessionId>`，不修改用户原有的 tmux 配置或会话。正常使用无需手动输入这些内部名称。

## 操作步骤与保留范围

终端顶部“操作步骤”默认折叠，记录实际提交的命令、Agent 输入动作、控制权切换和连接变化；每页 50 条，每会话保留最近 1000 条。当前运行的命令去重账本与可见步骤保留上限分开，翻页或淘汰旧步骤不会导致命令被重放。后台重启将未确认的命令标为 unknown。

本功能不记录模型的内部推理，也不会自动拆解脚本内部每一个动作。第一版没有单独的远端文件传输/编辑工具，文件变更通过终端命令进行，步骤中显示实际命令。Shell 初始化会读取 ~/.bashrc，再安装提示符钩子；手动覆盖 PROMPT_COMMAND/DEBUG trap、替换 Shell 或关闭终端回显可能影响自动识别，此时应按交互程序读屏处理，不能重复执行命令猜测状态。

实时画面是实际终端。操作步骤和普通 Shell 输出可保留，但不保证断线期间每次 TUI 重绘都可录像回放；完整离线录制需要后续的远端记录组件。
