# CPU 与内存占用

- **会话**：运行中会话的侧栏行右侧，以及当前会话标题旁，显示 CPU 与内存。统计包含终端 shell、Agent 和它们的子进程。停止后清除实时读数；重新启动按新运行记录采样。
- **项目**：项目侧栏行右侧，汇总此项目全部运行中会话。折叠项目或搜索筛选不会改变统计范围；没有运行中会话时不占用行内空间。
- **工作台**：侧栏底部一行，包含 Electron 桌面进程、后台服务、终端、Agent、Git、插件和采样程序等子进程。共享公共开销归工作台，因此总量通常大于项目之和。

显示例如 `1.2% · 245M`，标题旁额外标明 CPU。K/M/G 按 1024 换算；悬停可查看进程数、统计范围和更新时间。数值使用固定宽度数字，不随读数跳动挤动布局。

CPU 是两次采样之间的时间占比，并按整机逻辑处理器数归一化：100% 表示占满全部逻辑处理器，与 Windows 任务管理器的整机口径一致。初次采样显示 `—`，下个区间开始有 CPU 值。新出现的子进程从下个区间计入 CPU。内存为进程工作集/RSS 的总和，包含驻留共享页，不等于整机唯一物理内存或分配上限。采样间隔内已退出的短命进程可能无法捕获。

前台每 3 秒更新一次，切回窗口立即刷新，后台暂停轮询。一次系统快照汇总全部会话，不为每个会话启动采样命令；Windows 复用一个隐藏的 PowerShell/CIM 采样进程，闲置 20 秒自动释放，完整退出时停止。Linux 读取 `/proc`，macOS 使用 `ps`。采样失败显示 `—` 并自动重试，不用 0 掩盖读取失败，不影响终端输入、Git 或会话管理。

需要后台 API 14；更新软件后从托盘完整退出旧后台再启动即可。此功能无需 Agent 插件配合。
