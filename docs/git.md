# 源代码管理

左侧切换 **会话 / 文件 / Git**，选择 Git 即打开源代码管理（快捷键 Ctrl+Shift+G）。顶部的分支信息和项目右键的“Git 管理”也会打开这个侧栏。主区终端、历史和预览独立切换，操作不停止或重建终端。

## 暂存与提交

- **更改**列出未暂存和未跟踪文件，**已暂存的更改**列出暂存区内容。同一文件可以同时出现在两组中。
- 点击文件在主区预览差异。“未暂存”比较暂存区与工作目录，“已暂存”比较 HEAD 与暂存区。预览显示增删颜色、两侧行号和上下文；可切换比较范围和刷新。
- 每行 **+ / −** 分别暂存或取消暂存该文件；也可勾选多份文件后使用分组标题按钮批量操作。每批最多 500 个文件，筛选和“显示更多”便于查找；最多列出 2000 份更改，超出会提示。
- 输入提交信息后点击 **提交已暂存的更改**，或 Ctrl+Enter。只提交暂存区，不会自动把工作目录中后续修改或其他未暂存文件加入提交。
- 取消暂存保留文件内容，首次提交之前也可使用。新文件、删除与重命名使用 Git 原生索引语义处理。提交信息草稿按项目保存，切换视图或项目后保留，成功提交后清空；失败时保留。
- 提交使用本机 Git 身份和提交钩子；缺少身份、钩子拒绝或有冲突时显示 Git 错误。冲突解决后可暂存对应文件，合并、变基等未完成操作请在终端完成。

差异预览为只读，过大时明确提示截断，二进制文件提供状态说明。字体与字号统一在 **设置 → 文件预览** 调整，沿用已有预览设置。

## 分支与远端

展开 **分支与远端**，可查看仓库根目录与上游、选择远端，并在本地分支与远端分支之间切换。项目位于仓库子目录时，源代码管理作用于整个仓库；从项目文件预览打开差异时，路径按当前项目解析。

- **刷新状态**只读取本地状态，窗口获得焦点和前台每 15 秒刷新。领先/落后以最近获取为准，不自动连接远端。
- **获取远端**按仓库 fetch 配置更新远端跟踪分支，并清理远端已删除的分支引用；不更改工作目录或删除本地分支。
- **拉取**仅做快进更新；分叉时保留现场，在终端合并或变基。
- **推送 / 发布当前分支**只推送当前分支的已提交内容；首次发布会设置上游。
- **同步远端**获取、快进拉取，再推送本地领先的提交。失败时说明已完成的步骤。
- **本地分支 / 远端分支**切换查看范围，可按名称筛选。远端列表随所选远端变化，显示最近获取的分支，排除 `origin/HEAD` 等符号引用；不在后台自动联网，点击“获取远端”刷新。
- **远端分支切换**会优先切换到已有本地跟踪分支，保留它的本地提交；否则默认以远端分支名创建本地跟踪分支并设置上游。需要时可调整本地名称。同名本地分支若跟踪关系不同，须换名或从本地列表切换，不会覆盖或重置它。
- **本地分支切换**选择已有分支并切换。若任一切换会覆盖本地改动，Git 会拒绝，不自动暂存或丢弃改动。Git worktree 占用、冲突或操作未完成时也保留 Git 原生保护。
- 已删除、提交已变化或失效的远端分支会提示重新获取或刷新。空列表说明需先获取；自定义 fetch 映射也按仓库配置识别，远端同名分支互不混淆。超过 2000 个远端分支会提示截断。
- 远端分支功能需要后台 API 19。旧后台会显示更新提示，本地分支切换继续可用。

Git 操作可在终端运行时进行，保留 PTY/PID、会话和输入输出。软件使用本机 Git 与已有凭证/SSH 配置，不保存 Git 密码；需要登录时可在终端完成认证。切换侧栏不会取消正在运行的 Git 操作，结束时会提示；托盘退出会取消 Git 子进程。

不提供丢弃文件、强推、重置工作目录或分支删除。
