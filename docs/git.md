# 轻量 Git 管理

顶部的分支入口显示当前项目所属仓库的分支、改动数量、领先/落后提交数。折叠顶部信息后仍保留入口；项目右键菜单也可打开 Git 面板，不会切走当前会话。

面板展示仓库根目录、上游、已暂存/未暂存/未跟踪/冲突统计，以及前 100 项改动。项目位于仓库子目录时，操作作用于整个仓库工作区。普通目录、尚无提交的仓库、游离 HEAD、没有 Git 或没有远端都会给出对应状态。

- **刷新状态**：只读取本地状态。窗口获得焦点时和前台每 15 秒更新，不自动连接远端。领先/落后以本地远端跟踪引用为准。
- **获取远端**：获取所选远端的新提交，不更改当前工作区。
- **拉取**：获取当前上游的提交并仅执行快进更新。没有上游时先发布分支；分叉时保留现场，交给终端合并或变基。
- **推送**：只推送面板中当前分支的已提交内容到显示的目标，使用普通推送。不会附带其他分支或标签。
- **发布当前分支**：没有上游时，将当前分支发布到所选远端的同名分支并设置上游。
- **同步远端**：获取、快进拉取，再推送本地领先的提交；没有上游时发布当前分支。任一步失败会停止并说明已完成的步骤，不会自动回滚远端。
- **本地分支切换**：展开“本地分支与工作区改动”，选择已有的本地分支并切换。

所有 Git 操作都可在终端运行时使用，不停止或重建终端，也不改变会话、启动命令与 PTY/PID。未提交改动不再禁用操作：Git 允许保留不受影响的改动；如果拉取或切换会覆盖本地文件，则拒绝并列出相关文件，不会自动暂存或丢弃改动。存在合并、变基、拣选、还原或冲突时，先在终端处理。

软件使用本机安装的 Git 和已有凭证/SSH 配置，不保存 Git 密码。未登录时可在终端完成认证后重试。每条远端命令最多等待两分钟；关闭面板可继续使用工作台，操作完成后会提示。托盘退出会取消仍在执行的 Git 子进程。

暂不提供暂存/提交、差异编辑、强推、自动暂存、重置或分支删除；这些操作可在项目终端完成。
