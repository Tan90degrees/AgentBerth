# 笔记 Wiki 使用指南

## 第一次使用

打开活动栏的「知识库」，点击首次使用提示中的「配置地址、模型与鉴权」。在同一面板填写 OpenAI 兼容服务地址、文本模型、视觉模型与 API Key，保存后测试连接。Ollama、LM Studio 等不要求鉴权的本地服务，可关闭「服务需要 API Key」，无需填占位密钥。

知识库默认收起工作台项目侧栏以保留阅读空间；再次点击活动栏图标可展开，布局会按视图记住。升级后若后台仍是旧版本，先停止会话并使用「更新后台」，无需清理数据目录。

## 导入与任务

- 新增素材可手动保存文字和图片，也可选择多个 PDF、Markdown、UTF-8 文本文件，再点击「开始导入文件」。选择文件本身不会上传或调用模型。
- 文件导入可选择是否生成待审阅提案。每个文件分别显示进度与结果，单个失败不阻断其他文件；可以取消剩余导入，或只重试失败文件。已成功保存的素材会保留。
- PDF、文本和图片素材不再设置导入字数、单文件大小或图片数量上限，原文与原始附件完整保存；上传按小分片写入临时磁盘，PDF 解析在后台任务执行。实际可处理规模取决于本机可用磁盘、内存和模型服务能力。扫描 PDF 没有文本层时会明确说明。
- `raw/inbox` 仍支持自动采集。PDF 的原文件与提取页码位置会一并保存。
- 在「任务」中查看排队、执行、完成、失败和取消状态，取消进行中的模型请求或重试失败任务。后台重启后不会自动重放付费请求，未完成任务会提示手动重试。
- 长素材会按有序窗口逐片送入模型，所有片段均处理后合并为提案，末尾内容不会因上下文预算被省略；图片逐张读取，提案记录处理字符数和分片数。模型的单次上下文窗口和请求超时只限制一次请求，不会截断保存在本机的素材。
- MCP 的素材清单、索引、页面和原始素材支持按需分页。返回 `hasMore` 时，把 `next` 作为下一次的 `offset`；原始素材还支持 `quote` 定位及 `section=vision` 读取图片理解，不会只暴露素材前缀。
- 会话导入按工作区分组，显示完整会话名称、会话 ID、原生会话 ID，支持名称/目录/ID 搜索。ACP 从首条记录逐页读取到导入开始时的最后序号，CLI 会话重新读取完整原生记录，绕过界面历史预览的条数与字数裁剪。
- 编译完成后可直接打开对应提案。任务结果会提示发布、跳过的实际页数和原因；后台完成不会强行切走已经进入其他页面的用户。

## 编辑、审阅和出处

页面、素材文字、Skill、知识库约定和审阅意见会自动保留编辑草稿。切换标签、关闭视图或配置重载后，可从草稿栏继续；放弃草稿需要确认。密码与 API Key 不属于编辑草稿。浏览器不允许恢复文件选择，重开后需重新选择附件，文字草稿会保留。

草稿保留编辑前的版本标识：别人已经修改页面时，恢复旧草稿不会绕过冲突检查。

保存请求较慢时可以继续输入。已提交的版本保存成功后，后续输入仍保留在草稿中；页面会继续停在编辑状态。切到其他页面后，迟到的保存结果不会把你切回去。问题提交成功后可以继续写下一问，上一问完成时不会清空新问题，也不会抢走正在阅读的历史回答。

审阅时可以逐页查看完整 diff、编辑正文、选择是否发布该页。对人工编辑页，需要显式允许本次合并；发布时仍检查提案生成后的版本变化。手工审阅修改过的正文继续受人工编辑保护。

原始素材支持全文分页阅读、图片预览及下载、原 PDF 下载和按 PDF 页码定位提取文本。点击页面或回答中的「定位原文」，会跳到逐字引文所在的片段并高亮。

## 查找、删除与恢复

页面搜索覆盖标题、摘要、正文和标签，可按类型、标签筛选并分页浏览。问答按全文搜索，历史分页展示，新产生的记录会持续保存，不再只保留最近二十条。编译提案、任务和回收站也有分页入口。

删除页面或素材前会展示引用影响。删除后进入回收站，素材附件会保留，可以恢复原有标识和出处关系。同名页面已经重新创建时，恢复会拒绝覆盖当前内容。

## 备份与迁移

在知识库「设置 → 备份与迁移」导出 ZIP，包含页面、素材、图片、原 PDF、提案、历史、问答、回收站和编辑草稿。模型密钥及主程序的插件配置不会导出。

导入 ZIP 前会校验格式、路径和记录，并预览新增、相同与冲突数量。默认仅补充不存在的内容；覆盖同名内容需要明确确认。恢复前会自动保存快照，可在同一界面恢复。当前 ZIP 传输上限为 64 MiB，展开上限为 256 MiB。

「恢复自动快照」会完整恢复当时的知识库，包括移除快照后新增的页面、素材、附件和草稿。确认前会显示移除和覆盖的文件数量；操作前再保存一份快照，因此本次恢复也可以撤销。模型密钥、主程序配置、收件箱和已有自动快照不会被清理。恢复前需完成任务、等待取消处理结束，并完成或取消 PDF 上传。备份中的未完成任务会立即显示为待手动重试，不会自动重放模型请求。

备份含原始笔记内容，请在自己可控的位置保存。知识库供当前工作台统一使用；开启 Agent 读取权限后，所有连接工作台的 Agent 可读取，尚不按项目隔离。

## 工作台交互

点击项目名称或左侧箭头均可折叠、展开项目，会保存各项目状态并在重新打开程序时恢复。信息、告警、错误集中在右上角通知中心；新通知自动展开，五秒后收起，通知历史和撤销/重试操作仍可再次打开查看。
