# 笔记 Wiki 使用指南

## 第一次使用

打开活动栏的「知识库」，点击「模型未配置」旁的「配置模型」。在插件配置中填写文本服务地址、文本模型和图片模型；在同一「修改模型配置」面板分别填写文本与图片 API Key，保存后可分别测试两套连接；知识库设置中的高级凭据管理也可单独修改密钥。图片服务地址留空时沿用文本地址，未单独保存图片密钥时沿用文本密钥；填写独立图片地址后只使用图片密钥，不会向该服务发送文本密钥。独立无鉴权图片服务可关闭「独立图片服务需要 API Key」。Ollama、LM Studio 等不要求鉴权的本地服务，可关闭「服务需要 API Key」，无需填占位密钥。

知识库默认收起工作台项目侧栏以保留阅读空间；再次点击活动栏图标可展开，布局会按视图记住。升级后若后台仍是旧版本，先停止会话并使用「更新后台」，无需清理数据目录。

操作结果、任务完成和错误统一出现在右上角「通知与告警」，新消息展开 5 秒后收起，可再次打开查看历史。Wiki 内容区仅保留「查看素材」「查看提案」等结果操作按钮。

## 导入与任务

- 「新增原始素材」可粘贴正文，或上传一个 ZIP、Markdown、UTF-8 文本、PDF、PNG / JPEG / WebP / GIF。多份文件请按原有层级打包成 ZIP。每次上传形成一组原始素材，补充正文随组保存。选择文件时不会上传或调用模型。
- 原始文件存放于 `raw/files/<素材 ID>/`，保留文件字节、名称和相对目录。ZIP 使用流式展开，拒绝越界路径、符号链接、路径冲突和不支持的文件类型。归档展开保护为 10,000 条目和 4 GiB，单文件上传仍受实际磁盘和内存能力约束。归档校验或解析失败时，整组原件不会部分提交。可以取消或从同一导入表单重试。
- 保存后可选择编译。模型先浏览原始目录，再按相关性选择下一个文件。长文件按窗口继续读取，图片在选中时交给配置的视觉模型，整组完整处理后合成一份待审阅提案。缺少视觉模型或扫描 PDF 缺少文本层时，原件仍可浏览和下载，编译会说明缺少的能力。
- 在素材详情沿目录浏览，点文件名预览。Markdown 的相对链接和图片仅在该组素材内解析，文本可继续翻页，PDF 可按页查看提取文本并下载原 PDF。预览的「引用 Markdown」给出稳定引用，用于页面中的文件链接和内嵌图片。
- 点击素材栏「自动采集 / 会话沉淀」，可查看实际的完整监听目录、待处理文件、归档数量与失败原因。把 PDF、Markdown、UTF-8 文本或 JSON 放入显示的目录，文件停止写入后会自动保存为素材；也可点击「重新扫描」。PDF 原文件与提取页码位置一并保存。导入失败的文件保存在面板显示的 `failed` 目录，修正后移回采集目录重试。
- 自动采集和会话沉淀保存成功后立即触发已启用的自动编译，连续处理待编译素材并生成提案。模型尚未配置时也会保存素材，可在配置完成后编译；自动编译关闭时需手动操作。会话沉淀需要选择会话并点击「全量导入会话」，不会自行监听每次对话。
- 在「任务」中按状态筛选，取消进行中的任务，或重试失败、已取消且支持重试的任务。「删除记录」与「清空已结束记录」需确认，会保留进行中的任务与已保存的素材、提案、回答和页面。持续保留最近 200 条已结束任务；取消或中断的编译需要显式重试，即使已清理记录或重启，也不会自动重放付费请求。任务记录移除后可从原素材重新发起编译。
- 正文与旧素材继续按完整文本逐片处理。目录素材由模型根据现有证据选择下一个文件，导航只接受当前清单提供的子目录和下一页。模型返回重复目录页、无效路径或无法选定文件时，后台会选一个尚未读取的文件。当前文件的全文窗口处理完再选择下一份，记录处理字符数和窗口数，最后生成同一组提案。原始字节完整保存在本机。
- MCP 的素材清单、索引、页面和原始素材支持按需分页。返回 `hasMore` 时，把 `next` 作为下一次的 `offset`；原始素材还支持 `quote` 定位及 `section=vision` 读取图片理解，不会只暴露素材前缀。显式传入 `offset` 时优先按游标继续。对目录素材可在 `wiki_source` 中传入 `directory: ""` 浏览根目录，传入子目录名继续浏览，同样可传入 `path` 分页读取指定文本文件或 PDF 的提取文本。
- 会话导入按工作区分组，显示完整会话名称、会话 ID、原生会话 ID，支持名称/目录/ID 搜索。ACP 从首条记录逐页读取到导入开始时的最后序号，CLI 会话重新读取完整原生记录，绕过界面历史预览的条数与字数裁剪。
- 会话列表读取失败会保留上次结果并显示错误，可点击「刷新会话」重试。导入完成通知与任务中心显示实际记录数并提供「查看素材」；相同内容再次导入会复用原素材。
- 编译完成后可直接打开对应提案。任务结果会提示发布、跳过的实际页数和原因；后台完成不会强行切走已经进入其他页面的用户。
- 模型返回 JSON 代码块、前后说明文字、尾逗号或字符串内的直接换行时会进行兼容处理。非法属性名、多个 JSON 对象等情况会尝试一次模型格式修复；仍失败则保留素材，暂停该素材的自动编译，待手动重试或调整模型，避免反复产生请求。接口返回不完整流式数据或输出达到服务端 token 限制时会明确报错，不能把残缺结果当作完整提案。

## 编辑、审阅和出处

页面、素材文字、Skill、知识库约定和审阅意见会自动保留编辑草稿。切换标签、关闭视图或配置重载后，可从草稿栏继续；放弃草稿需要确认。密码与 API Key 不属于编辑草稿。浏览器不允许恢复文件选择，重开后需重新选择附件，文字草稿会保留。

草稿保留编辑前的版本标识：别人已经修改页面时，恢复旧草稿不会绕过冲突检查。

保存请求较慢时可以继续输入。已提交的版本保存成功后，后续输入仍保留在草稿中；页面会继续停在编辑状态。切到其他页面后，迟到的保存结果不会把你切回去。问题提交成功后可以继续写下一问，上一问完成时不会清空新问题，也不会抢走正在阅读的历史回答。

审阅时可以逐页查看完整 diff、编辑正文、选择是否发布该页。对人工编辑页，需要显式允许本次合并；发布时仍检查提案生成后的版本变化。手工审阅修改过的正文继续受人工编辑保护。

原始素材和生成页面分开保存，页面保持独立 Markdown 文件。可在页面正文嵌入 `![图注](wiki-source:<素材 ID>/<编码后的相对路径>)`。普通 Markdown 链接可打开原文件预览。点击「定位原文」可查看逐字引文，对目录素材会打开对应文件。

## 模型请求调度

在「修改模型配置」中设置「LLM 调用重试次数」（0–8，默认 2）和「LLM 最大并发请求数」（1–16，默认 2）。重试次数指首次调用之外的额外尝试；仅重试网络、请求超时、HTTP 408/425/429 及 5xx 错误，遵守有上限的退避与 Retry-After。鉴权失败、参数错误、格式错误、空输出和输出截断不会触发传输重试；JSON 格式修复仍最多一次。取消任务或停用插件会中断排队与退避。

文本、图片、连接测试及格式修复共用请求并发上限；不同任务可并行，单份素材中的图片也可并行，合并顺序与原文件顺序一致。并发处理不会绕过审阅、版本检查或写锁。配置和密钥只保存在本机，密钥不进入普通配置、编辑草稿或备份包。

## 查找、删除与恢复

页面搜索覆盖标题、摘要、正文和标签，可按类型、标签筛选并分页浏览。问答按全文搜索，历史分页展示，新产生的记录会持续保存，不再只保留最近二十条。编译提案、任务和回收站也有分页入口。

删除页面或素材前会展示引用影响。删除后进入回收站，素材附件会保留，可以恢复原有标识和出处关系。同名页面已经重新创建时，恢复会拒绝覆盖当前内容。

回收站支持单条「永久删除」和「清空回收站」，均需确认。操作无法从回收站撤销，会清理无引用的图片和原 PDF；其他内容仍使用的附件与已有备份会保留。

提案详情支持「删除审阅记录」，待审阅、已批准和已拒绝的记录均可删除。已发布页面与原始素材保留，对应的未保存审阅编辑会丢弃。正在编译或审阅时需先完成或取消任务。删除后不会自动重新生成该记录；需要再次生成时，在素材详情点击「编译为提案」。

## 备份与迁移

在知识库「设置 → 备份与迁移」导出 ZIP，包含页面、素材目录和原始文件、提案、历史、问答、回收站和编辑草稿。模型密钥及主程序的插件配置不会导出。

导入 ZIP 前会校验格式、路径和记录，并预览新增、相同与冲突数量。默认仅补充不存在的内容；覆盖同名内容需要明确确认。恢复前会自动保存快照，可在同一界面恢复。当前 ZIP 传输上限为 64 MiB，展开上限为 256 MiB。

「恢复自动快照」会完整恢复当时的知识库，包括移除快照后新增的页面、素材、附件和草稿。确认前会显示移除和覆盖的文件数量；操作前再保存一份快照，因此本次恢复也可以撤销。模型密钥、主程序配置、收件箱和已有自动快照不会被清理。恢复前需完成任务、等待取消处理结束，并完成或取消 PDF 上传。备份中的未完成任务会立即显示为待手动重试，不会自动重放模型请求。

备份含原始笔记内容，请在自己可控的位置保存。知识库供当前工作台统一使用；开启 Agent 读取权限后，所有连接工作台的 Agent 可读取，尚不按项目隔离。

## 工作台交互

点击项目名称或左侧箭头均可折叠、展开项目，会保存各项目状态并在重新打开程序时恢复。信息、告警、错误集中在右上角通知中心；新通知自动展开，五秒后收起，通知历史和撤销/重试操作仍可再次打开查看。
