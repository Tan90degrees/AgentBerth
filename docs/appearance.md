# 外观设置

界面提供经典中性、蓝青、Claude 风格和液态玻璃四套配色，每套均可分别选择配色及浅色、深色或跟随系统。首次打开或未选择过配色的旧安装默认经典中性、深色；已有的深浅偏好继续保留。液态玻璃采用半透明面板、柔和渐变和局部背景模糊；不支持模糊或开启系统减少透明效果时使用实色面板。

- **侧栏底部的太阳 / 月亮按钮**：一键切换深浅模式。
- **设置 → 外观**：分别选择配色及浅色、深色或跟随系统。选择立即生效并自动保存，不需要点击“保存设置”。方向键可切换选项。
- **跟随系统**：系统外观变化时自动更新；明确选择深色或浅色后，保持该选择。

**设置 → 外观 → 界面字体**：选择系统、现代无衬线、思源/Noto、衬线、等宽或自定义本机字体。自定义填写单个已安装的字体名称；缺少字形时使用系统回退，不下载字体。字体即时保存并同步主窗口及 HTML 插件，终端与文件预览保持各自字体设置。界面字号继续使用原来的缩放设置。

外观偏好保存在当前工作台设备，重启后保留，不改变项目、会话或默认终端配置。后台断开时也能调整。

终端与普通 Shell 的只读运行输出同步切换配色，保留当前终端实例、缓冲、选择和尺寸；不会重启 CLI 或 PTY。支持自动主题的 TUI 可通过 OSC 10/11/12 查询当前前景、背景和光标颜色，并通过 DEC 2031 订阅运行中的深浅变化。协议由后台统一响应，隐藏、切换页面或 Agent 托管 SSH 时仍可工作，不会向未订阅的 Shell 写入主题通知。TUI 输出的显式 RGB 颜色继续由 CLI 决定；固定主题或不处理主题通知的 CLI 需要使用其自身的自动/系统主题设置，工作台不会修改第三方配置或强制重启进程。

侧栏、历史、设置、菜单、Git 面板和原生窗口背景使用同一套主题。终端滚动条继续保留独立空间，顶部仍可折叠。

## 通知与界面文案

会话恢复进度与完成结果、恢复失败、后台可用更新和插件操作反馈统一进入右上角「通知与告警」。新通知展开 5 秒后收起，历史保留；重复状态快照及重连不会反复弹出同次恢复通知。「查看会话」保留失败报告，「更新后台」仍须先停止运行中的终端。

界面用控件名称、分组、状态与结果表达功能，不常驻教学或实现说明。详细用法进入使用文档，设计理由保留在代码注释；实际错误、输入格式、授权及删除后果继续在对应操作中展示。

深浅主题协议需要 API 62 后台；独立配色的默认颜色联动需要 API 64。API 62–63 保留深浅联动，界面配色和字体即时可用；兼容挂接旧后台时保留原终端工作，停止活跃会话后使用通知中的「更新后台」启用完整联动，无需清理数据目录。
