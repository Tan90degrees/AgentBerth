# 外观设置

界面采用中性色和紧凑布局，提供浅色、深色与跟随系统三种外观。首次打开默认跟随操作系统。

- **侧栏底部的太阳 / 月亮按钮**：一键切换深浅模式。
- **设置 → 外观**：选择浅色、深色或跟随系统。选择立即生效并自动保存，不需要点击“保存设置”。方向键可切换选项。
- **跟随系统**：系统外观变化时自动更新；明确选择深色或浅色后，保持该选择。

外观偏好保存在当前工作台设备，重启后保留，不改变项目、会话或默认终端配置。后台断开时也能调整。

终端与普通 Shell 的只读运行输出同步切换配色，保留当前终端实例、缓冲、选择和尺寸；不会重启 CLI 或 PTY。终端自身显式指定的 ANSI/TUI 颜色仍由 CLI 决定，工作台为文字提供最低对比度调整。

侧栏、历史、设置、菜单、Git 面板和原生窗口背景使用同一套主题。终端滚动条继续保留独立空间，顶部仍可折叠。
