# 本地模拟信息源

这是开发示例，不会随应用自动启用，也不访问外部服务。

1. 插件中心 → 加载开发目录，选择此目录。
2. Superagent → 信息源，选择“本地模拟源”，关联项目、协调 ACP Agent 和执行 ACP Agent。
3. 默认需要人工批准；如启用自动准入，必须明确列出授权 `actorId`。
4. 调用插件 `emit` 命令，提供稳定的 `id`、`threadId`、`actorId`、`title` 和 `text`。
5. 相同事件 ID 不会创建第二个任务。停用插件后，其发布句柄立即失效。

自定义来源使用相同的 `ctx.berth.source()` 接口，监听和认证逻辑由来源插件实现。
不要在 `apply()` 中等待事件发布；先完成注册，再从命令、事件监听器或已托管的定时任务中发布。
`emit()` 成功返回代表结果已持久化；抛出异常时，插件应保留事件，以相同 ID 稍后重试。

`reply()` 只在用户确认回传时调用，必须按 `idempotencyKey` 去重，并遵守传入的 AbortSignal。
本例把回执保存到自己的数据目录，不会向任何人发送消息。`loseAck` 选项用于验证回执丢失时的恢复行为。
